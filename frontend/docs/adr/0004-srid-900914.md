# ADR 0004 — SRID 900914 for spatial data

Status: Accepted · Owner: `gis-eos-architect`

## Context
The `zimbabwe.gpkg`-sourced layers use SRID 900914.

## Decision
Treat SRID 900914 as equivalent to WGS 84 CRS84 / EPSG:4326 and handle it in SQL. No blanket
client-side reprojection.

## Consequences
- Only reproject (via `proj4`) a source that is genuinely a different CRS.
- Keep geometry in 900914 through the tile pipeline.
