# Phase 2 Admin System - Quick Start Guide

## 🚀 Getting Started in 5 Minutes

Welcome to the Phase 2 Admin System! This quick start guide will get you up and running in just 5 minutes.

---

## 📋 Prerequisites

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Admin account credentials
- Internet connection

---

## 🔐 Step 1: Login

1. **Navigate to**: `http://localhost:5175/admin`
2. **Enter credentials**:
   - Email: `admin@vungu.gov.zw`
   - Password: `admin123`
3. **Click**: "Sign In"

✅ **Success**: You're now on the admin dashboard!

---

## 🎯 Step 2: Access Phase 2

1. **From admin dashboard**: Click "Phase 2 Administration"
2. **Or go directly**: `http://localhost:5175/admin/phase2`

✅ **Success**: You're now on the Phase 2 dashboard!

---

## 🧹 Step 3: Try Data Cleaning

1. **Click**: "Create Cleaning Job" button
2. **Fill in basic details**:
   - Job name: `Test Job`
   - Description: `Learning the system`
3. **Upload**: Any CSV or GeoJSON file
4. **Click**: "Start Cleaning"

✅ **Success**: Your first data cleaning job is running!

---

## 🎨 Step 4: Explore QML Templates

1. **Click**: "View Templates" button
2. **Browse**: Available style templates
3. **Click**: Any template to see details
4. **Try**: "Validate QML" with sample code

✅ **Success**: You've explored the QML system!

---

## 🔄 Step 5: Check Workflows

1. **Click**: "View Workflows" button
2. **Review**: Active and pending workflows
3. **Click**: "Create Workflow" to start a new one
4. **Fill in**: Basic workflow information

✅ **Success**: You've created your first workflow!

---

## ⚡ Step 6: Test Batch Processing

1. **Click**: "Create Batch Job" button
2. **Select**: Job type (Bulk Import/Export)
3. **Configure**: Basic settings
4. **Click**: "Start Batch Job"

✅ **Success**: Batch processing is working!

---

## 🔒 Step 7: Explore Security Features

1. **Click**: "Refresh Security Data" button
2. **View**: Security metrics and events
3. **Click**: "Test Rate Limiting" to see protection in action
4. **Click**: "Security Dashboard" for advanced monitoring

✅ **Success**: Security features are active!

---

## 📚 Step 8: Access Training Materials

1. **User Manual**: Click "Open User Manual" → Choose format (MD/XML)
2. **Admin Guide**: Click "Open Admin Guide" → Choose format (MD/XML)  
3. **Video Tutorials**: Click "View Tutorials" → Choose video portal or scripts

✅ **Success**: All training materials are available!

## 🆘 Need Help?

### **Common Issues:**

**Q: Login fails with "Invalid credentials"**
A: Check email and password. Use `admin@vungu.gov.zw` / `admin123`

**Q: Data cleaning job shows "Failed"**
A: Check file format. Supported: CSV, GeoJSON, SHP, KML, GPKG

**Q: Can't upload files**
A: Check file size limit (100MB) and format

**Q: Security dashboard shows no data**
A: Click "Refresh Security Data" to load metrics

### **Get Support:**

1. **Check Console**: Press F12 for browser console errors
2. **Read Documentation**: User Manual has troubleshooting section
3. **Contact Support**: security@vungu.gov.zw

## 🎯 Pro Tips

### **Data Cleaning:**
- Start with small files (under 10MB)
- Use CSV for tabular data
- Check data quality before processing

### **QML Templates:**
- Test templates with sample data first
- Backup original templates before editing
- Use consistent naming conventions

### **Workflows:**
- Set clear approval steps
- Configure notifications for important stages
- Monitor workflow performance regularly

### **Security:**
- Review security metrics daily
- Set up alerts for critical events
- Regularly update user permissions
