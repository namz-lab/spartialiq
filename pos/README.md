# Tillbook

Point of sale, recurring stock, quotations, receipts and books.

## Web

```bash
cd pos
npm install
npm run dev
```

Opens on http://localhost:5180/

## Desktop installer (Windows)

```bash
cd pos
npm install
npm run desktop:pack
```

The installer lands in `desktop/dist/Tillbook-Setup-1.0.0.exe`.

## Vercel

This folder is a static Vite app. Deploy the `pos` directory as the project root.
